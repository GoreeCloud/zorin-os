## Implemented V1.4.1 contract

Care treats V1.4.1 as additive hardening over the V1.4.0 optical foundation.

The repository-local implementation provides:

- bounded Content-Aware Frost behavior;
- Semantic Blur Protection;
- bounded depth hue shift and environmental warmth;
- optional Environmental Color Memory with an 8% maximum influence;
- Forced Colors / HighContrast, Reduced Transparency, Increased Contrast, and Reduced Motion precedence;
- fail-safe context-adapter exception handling;
- `Full`, `Balanced`, `Efficient`, and `Durable` performance levels;
- downgrade-only in-session performance governance;
- bounded requested/accepted performance evidence and downgrade reason;
- local/no-telemetry/no-remote-context behavior.

When a governed signal adapter throws, Care does not propagate the exception through ordinary optical resolution. It collapses to `solid-accessible`, forces Forced Colors and Reduced Transparency semantics after overrides are composed, disables blur and decorative memory tint, and exposes only the bounded adapter status `failed-safe`. Caller overrides cannot re-enable decorative optics for that failed resolution. Optional local error-observer failure is swallowed so diagnostics cannot defeat the accessibility fallback.

Care's default runtime does not collect wallpaper pixels, camera input, telemetry, analytics, network state, remote context, or device identity to drive optics. Any future environmental signal source requires separate Privacy Shield and Wardveil authority.

## Native GTK3 mapping

GTK3 cannot claim compositor-authoritative backdrop sampling or unsupported rendering effects. Care therefore resolves bounded Optical Intelligence state and maps it to native semantic classes. Unsupported decorative effects degrade before content, focus, accessibility, or maintenance correctness.

Care retains application-owned responsive desktop composition states:

- `compact`;
- `narrow-desktop`;
- `desktop`;
- `wide-desktop`.

Those states are Care layout behavior, not the definition of Glaze UI V1.4.1 and not claims of Phone, Tablet, TV, or other product support.
